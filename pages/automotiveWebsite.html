Overview

A multi-page website for a Dodge Charger campaign, built without a single line of JavaScript.

Designed and built entirely in HTML and CSS — no frameworks, no JavaScript, no interactivity. The goal was to see how far pure markup and styling could go in creating an immersive campaign feel for a Dodge Charger brand site. Every section was crafted as a layout and visual design exercise.

Role UI Design & Development
Year 2025
Stack HTML, CSS
Duration 2 weeks
Highlights
  • 01

    Pure CSS only

    Every layout, hover effect, and visual detail built without a single line of JavaScript.

  • 02

    Multi-page structure

    Home, vehicle explorer, support page, and dealer finder — consistently designed across every page.

  • 03

    Layout & composition focus

    The project was about pushing how far HTML and CSS alone can go in creating an immersive, editorial-feeling web experience.
