Overview

A full restaurant website for a fictional seafood spot on Santa Monica Pier, built with React.

Dock & Bramble is a complete multi-page restaurant website built with React — home, menu, contact, and gallery pages. The design leans into a dark navy and warm cream palette that feels coastal and considered, with a menu page that actually reads like a real restaurant menu should.

Role UI Design & Development
Year 2026
Stack React, HTML, CSS
Duration 1 week
Highlights
  • 01

    Full React app

    Multi-page with React Router, component-based architecture, and a consistent design system across every page.

  • 02

    Real menu design

    A full menu page with starters, mains, desserts, and drinks — complete with tags like Chef's Pick and Seasonal.

  • 03

    Contact & location

    Contact form and embedded Google Map with address, parking, and transit info — the kind of detail that makes a fictional project feel real.
